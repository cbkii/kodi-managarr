Install in Kodi

  1. Open Settings → System → Add-ons.
  2. Enable Unknown sources when required.
  3. Open Add-ons → Install from zip file.
  4. Select the downloaded repository ZIP.
  5. Open Install from repository → Kodi Managarr Repository → Context menus.
  6. Install Kodi Managarr.
